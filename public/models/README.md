# Frozen model artifacts

| File | Contents |
| --- | --- |
| `bundle.json` | Version, feature order, dense weights, preprocessing, output transforms, interval adjustments, soil thresholds, and evaluation |
| `evaluation.json` | Aggregate, unseen-site, and per-site metrics plus split/sample context |

Both files are generated by `scripts/train.py`. The Node engine, shared reference inference, and browser Model Lab consume the same frozen bundle. Browser-trained local candidates are stored in IndexedDB and do not overwrite these files.

Regenerate both artifacts together when training changes. Keep `public/data/` forecasts and samples aligned with the bundle and change the model version when semantics change. Do not edit metrics independently of the trained result.

Read [model methodology](../../docs/models.md) for targets, baselines, chronological partitions, uncertainty, and limitations. Verify changes with `npm test` for export/reference parity and `npm run test:e2e` for browser inference and calibration.
